# PROJECT_RULEBOOK

1. Every feature must reduce overwhelm, improve idea evaluation, increase monetization, or increase freedom.
2. Schema-first changes: update Prisma schema before API/UI assumptions.
3. No feature sprawl beyond defined modules.
4. AI output governance: recommendation labels, prompt version, model, input/output provenance.
5. Security baseline: bcrypt, JWT, validation, rate-limit, ORM protection, env validation.
6. Calm UX baseline: minimal options, generous spacing, clear hierarchy.
