# PRODUCT_SPEC

Founder Control Panel is a founder cognitive operating system designed to reduce overwhelm, improve idea decisions, and convert excess ideas into monetizable assets.

## Core modules
- Mission Dashboard
- Active Project Limit (max 3 ACTIVE)
- Weekly Founder Review
- Idea Capture Vault
- Idea Bank (search/filter)
- Founder Decision Engine
- Life Alignment Filter
- $10K Idea Detector
- Blueprint Generator
- Idea Compression Engine
- Overwhelm Kill Switch
- Blueprint Marketplace
- Automation Systems Module

## Experience requirements
- calm UI
- one major decision per screen
- low cognitive load
- clear AI recommendation labeling
